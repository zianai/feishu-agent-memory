# 产品介绍 · Agent 记忆系统（agent-memory skill）

> 面向使用者/评委的一页纸介绍：它是什么、为什么做、怎么实现、带来什么价值，附上手指南与 Demo 脚本。
> 架构细节见 `memory-system-design.md`；本页只讲清楚四件事。

## 一句话

让任意 AI agent 在飞书里获得**跨会话记忆**：记住你的偏好、事实、目标与任务经验——
并且记忆不是黑盒，而是一张你随时能看、能改、能删的多维表格。

## 它是什么

一个可安装的 agent skill（`skills/agent-memory`）+ 一个飞书多维表格模板。
装到任意 agent（coding agent / Coze / Dify / 任何能调 LLM 的运行时）后：

- **读**：agent 回答前自动召回相关记忆注入上下文（用户画像 + 任务经验 + 会话摘要 + 近期消息）；
- **写**：会话静默后自动沉淀值得长期记住的信息，哈希查重、冲突旧记忆软删归档；
- **治理**：低置信记忆进「待确认」视图，人改一行表格即完成纠错；「记忆健康度」仪表盘随时观测。

## 为什么做

1. **AI 助手的通病是失忆**：每次会话从零开始，用户反复交代同样的事（"别用表格"、"我对辣过敏"）。
2. **通用记忆方案是黑盒**：向量库存在别人服务器里，用户看不见里面记了什么、更没法改错。
3. **我们的协作本来就发生在飞书**：会话在 IM 里、业务数据在多维表格里——
   记忆应该长在工作流本身，而不是挂在旁边的第三方服务。这也是"飞书 + AI"的正确结合方式：
   **AI 是飞书里一个有账号、守规矩、干完活留记录的同事，而不是一个外挂**。

## 怎么实现（飞书与 AI 各自承担什么）

| Agent 系统需要 | 本方案用飞书的什么 |
|---|---|
| 会话容器 + 交互入口 | IM 群聊/单聊（消息天然持久化，不自建缓存） |
| 结构化长期记忆（黑板） | 多维表格「用户画像 / Agent 经验」表，人机共同读写 |
| 事件驱动 | `im.message.receive_v1` 触发读链路；cron 静默巡检触发写链路 |
| 人工闸门 | 「待确认」视图（置信度 <0.6）+ 证据原文溯源 |
| 观测 BI | 「记忆健康度」仪表盘 + `memory-stats.sh` |

AI（LLM）承担全部判断：检索精排（替代向量检索）、沉淀判重/冲突识别、置信度评估、滚动摘要。
Agent 与 LLM 的交接是**严格字段化 JSON 协议**（枚举白名单 + 数值截断防御，非法值降级不报错）——
这是系统可靠的原因之一。另一条原则是降级哲学：**记忆挂了绝不阻塞回答**，所有故障都有兜底。

## 带来了什么价值

- **记忆透明可纠错**：用户在 Base 里直接改一行 = 纠错完成，agent 下次读到的就是对的；
  黑盒向量库做不到。
- **可审计**：每条记忆带证据原文、来源会话、置信度、置换链（archived 旧版本保留）。
- **可复用**：不依赖任何收费平台——一个 skill 包 + 一份 Base 模板 + 三步上手，
  任何有飞书账号的人可复现（表结构/协议/仪表盘搭建全部有文档）。
- **工程上站得住**：幂等（哈希查重 + 水位线）、冲突软删（Base 无事务下的安全选择）、
  降级表明确到每一种故障。

## 上手指南（三步）

1. **建库**：复制模板 Base，或按 `memory-system-design.md` 第 3 节建三张表 + 仪表盘
   （命令行一键搭建见 `references/dashboard.md`）；
2. **装 skill**：把 `skills/agent-memory` 放进你的 agent 的 skills 目录，
   改 `scripts/config.env` 里的 base_token / 三个表 ID；lark-cli 登录并开通 Base 读写；
3. **用起来**：群里 @机器人 正常对话即可；可选配置 cron 跑 `memory-consolidate.sh` 无人值守沉淀，
   `memory-stats.sh` 输出健康度日报。

## Demo 脚本（3 分钟实机演示）

| 分钟 | 演示 | 说明什么 |
|---|---|---|
| 0:00-0:20 | 痛点 | 同一个问题问机器人两遍，两次都失忆 |
| 0:20-1:00 | 沉淀 | 对话结束巡检触发，Base「用户画像」表出现新记忆行：内容/分类/重要度/**置信度**/证据原文 |
| 1:00-1:40 | 透明治理 | 打开「待确认」视图：低置信记忆在等人核对；**直接在表格里改一行**完成纠错 |
| 1:40-2:20 | 召回 | 再次提问，回答里自然用上了记忆（且引用的是刚修正过的内容） |
| 2:20-3:00 | 观测 | 「记忆健康度」仪表盘：总量/分类分布/待确认数/命中次数；`memory-stats.sh` 一键日报 |

收尾一句话：记忆不是存在哪个厂商的服务器里，而是存在你自己的飞书多维表格里——
**看得见，改得动，带得走**。
